# Full-paper calibration matrix

**Status:** complete for the project closeout. The matrix contains 13 same-venue TACO articles, five influential/foundational papers, and seven adjacent full papers. The required 12+5+5 threshold is therefore exceeded. “Full paper inspected” means the substantive paper, not only an abstract, was reviewed; it does not imply independent replication. Bibliography counts are reported only when they were directly available, otherwise they are explicitly not recounted.

## Decision distilled from the matrix

The same-venue and closest adjacent systems consistently connect their abstraction to an implementation, compiler/runtime/hardware mechanism, established or public workloads, and measured performance or quality. This project connects a finite declaration language to a producer and checker, but it does not connect that language to a native server, concurrent reclamation protocol, GPU kernel, public trace, or measured overhead. The calibration therefore preserves the formal boundary result while resolving the intended TACO significance gate negatively.

## Calibration groups and stop rule

- **Same venue:** selected TACO papers span memory safety, metadata, compilers, microarchitecture, simulation, virtual memory, and GPU memory optimization. They establish the venue’s implementation-and-evaluation norm for architecture/code-optimization claims.
- **Influential/foundational:** PagedAttention and FlashAttention show system/algorithm-to-kernel connection; PCC, Alive2, and CompCert establish the assurance lineage and the difference between checkable evidence and verified refinement.
- **Adjacent:** LServe, QUEST, MInference, SnapKV, vAttention, UNIQUE, and SPIN are the closest sparse-attention/KV/page works. The 2026 papers are especially important because they demonstrate that page-level selection and hierarchical metadata now have native runtime evidence beyond this project’s declarative model.

**Stop decision:** no paper in the inspected set supplies this exact finite lifetime-frontier plus shortest-path-certificate composition. That composition is specific, but its ingredients are standard and its practical bridge is absent. Specificity alone is insufficient for the intended systems venue; completing a runtime refinement and workload evaluation would be a separate research project, not a clerical completion step.
