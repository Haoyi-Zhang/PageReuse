# Publication resources

The manuscript targets ACM Transactions on Architecture and Code Optimization.
Publication instructions and policies are maintained by the publisher:

- [TACO author guidelines](https://dl.acm.org/journal/taco/author-guidelines)
- [ACM submission templates](https://www.acm.org/publications/authors/submissions)
- [ACM publications policies](https://www.acm.org/publications/policies)
- [ACM authorship policy](https://www.acm.org/publications/policies/new-acm-policy-on-authorship)
- [acmart package](https://ctan.org/pkg/acmart)

The accompanying source uses the supplied ACM class and bibliography style.
Its manuscript build instructions are in the sibling paper package. The
standalone computational artifact and figure generators use the documented
interfaces in this repository; they do not require the manuscript to execute.
Template copyright, the code license and the bundled font license are retained
with their respective materials.
